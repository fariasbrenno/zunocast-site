# zunocast-site

Site de vendas da Zunocast, publicado em https://zunocast.com pelo GitHub Pages.
HTML, CSS e JavaScript puros, sem etapa de build: o que está no repositório é o
que vai ao ar.

- `index.html`: a página.
- `assets/css/site.css`: visual. A paleta "Azul-noite No Ar" e as regras dela
  estão em `autoradio/docs/identidade-visual.md` (fora deste repositório).
- `assets/js/site.js`: a escala de sintonia do topo e os **links de compra de
  cada plano** (`CHECKOUT`, no começo do arquivo).

Repositório público (exigência do Pages no plano gratuito): nada de senha,
chave ou dado de cliente aqui.

Para ver no computador:

    python -m http.server 4180

e abrir http://localhost:4180.
